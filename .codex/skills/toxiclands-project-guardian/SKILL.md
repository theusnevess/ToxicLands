# ToxicLands Project Guardian

## Purpose

Ensure all implementations preserve:
- atmosphere;
- MVP scope;
- lore consistency;
- visual identity;
- GameMaker architecture;
- readability;
- performance.

---

# Rules

Always:
- preserve project identity;
- preserve atmosphere;
- preserve simplicity;
- preserve readability.

Never:
- create giant systems;
- introduce overengineering;
- change engine;
- break lore;
- redesign architecture unnecessarily.

---

# MVP Priority

Focus only on:
- movement;
- combat;
- atmosphere;
- exploration;
- basic enemies;
- room transitions;
- survival systems.

Ignore:
- multiplayer;
- procedural generation;
- large crafting systems;
- advanced AI;
- complex inventories.

---

# Art Direction Awareness

ToxicLands uses:
- dark rural biopunk;
- low-detail pixel art;
- strong silhouettes;
- wet surfaces;
- toxic lighting;
- minimal glow.

---

# Narrative Awareness

The protagonist:
- is ordinary;
- is vulnerable;
- survives through persistence.

Never make Saimon feel superhuman.
