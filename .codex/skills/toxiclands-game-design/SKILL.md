# ToxicLands Game Design Skill

## Purpose

Preserve the gameplay identity of ToxicLands.

Gameplay must reinforce:
- atmosphere;
- survival;
- tension;
- vulnerability;
- exploration;
- environmental storytelling.

The game must feel:
- oppressive;
- grounded;
- immersive;
- dangerous;
- readable.

# Core Gameplay Philosophy

ToxicLands is NOT:
- a power fantasy;
- a fast action spectacle;
- a combo-heavy action game;
- a heroic shooter.

ToxicLands IS:
- atmospheric;
- survival-oriented;
- methodical;
- grounded;
- exploration-focused.

---

# Core Loop

explore → survive → fight → collect → return → improve survival

Every system should support this loop.

---

# MVP Philosophy

MVP first.

Always:
- build the smallest playable version;
- validate before expanding;
- prioritize vertical slices;
- implement one system at a time.

Avoid:
- feature creep;
- large interconnected systems;
- unnecessary complexity.

---

# Player Philosophy

Saimon is:
- ordinary;
- vulnerable;
- persistent.

Gameplay should reflect this.

Movement:
- readable;
- grounded;
- slightly heavy.

Combat:
- desperate;
- dangerous;
- impactful.

Avoid:
- superhuman mechanics;
- flashy movement;
- exaggerated speed.

---

# Combat Philosophy

Combat should feel:
- tense;
- risky;
- brutal;
- improvised.

Encounters should:
- consume resources;
- create pressure;
- reinforce survival.

Avoid:
- combo systems;
- stylish action mechanics;
- arcade combat;
- enemy spam.

---

# Exploration Philosophy

Exploration is essential.

The world should reward:
- curiosity;
- observation;
- caution;
- navigation.

Environmental storytelling must matter.

Avoid:
- empty exploration;
- meaningless collectibles;
- repetitive filler.

---

# Survival Philosophy

Survival systems should create:
- tension;
- decision-making;
- vulnerability.

Key survival themes:
- filters;
- contamination;
- limited resources;
- unsafe environments.

Avoid:
- excessive micromanagement;
- tedious realism;
- bloated crafting systems.

---

# Enemy Design Philosophy

Enemies should feel:
- ecological;
- reactive;
- dangerous;
- biologically integrated.

Enemy categories:
- mutant flora;
- biomechanical animals;
- flesh-machines;
- hostile humans.

Avoid generic monsters.

---

# Boss Philosophy

Bosses must represent:
- adaptation;
- convergence;
- ecological horror;
- industrial decay.

Bosses should:
- reinforce narrative themes;
- feel memorable;
- alter player tension.

Avoid:
- giant damage sponges;
- spectacle-only encounters;
- random fantasy creatures.

---

# Pacing Philosophy

The game should alternate between:
- tension;
- silence;
- exploration;
- danger.

Silence is important.

Avoid constant stimulation.

---

# UI Philosophy

UI should:
- stay minimal;
- remain readable;
- support immersion;
- avoid clutter.

Avoid excessive HUD elements.

---

# Progression Philosophy

Progression should feel:
- practical;
- survival-oriented;
- grounded.

Examples:
- better filters;
- improved tools;
- safer traversal;
- resource efficiency.

Avoid:
- RPG stat inflation;
- magical upgrades;
- excessive skill trees.

---

# Validation Checklist

Before approving gameplay changes, verify:

- Does this reinforce atmosphere?
- Does this preserve vulnerability?
- Is the system readable?
- Is the scope still controlled?
- Does this support the core loop?
- Is this appropriate for MVP?
- Does it avoid generic action-game design?

---

# Response Format After Work

When finished, summarize:

1. gameplay systems affected;
2. gameplay goals;
3. atmosphere impact;
4. pacing impact;
5. survival impact;
6. risks or scope concerns;
7. what was intentionally avoided.
