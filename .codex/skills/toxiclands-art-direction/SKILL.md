# ToxicLands Art Direction Skill

## Purpose

Preserve the visual identity of ToxicLands.

ToxicLands is:

> 16-bit dark rural biopunk horror.

The world must feel:
- wet;
- dark;
- toxic;
- rural;
- organic;
- uncomfortable;
- alive.

# Visual Pillars

## 1. Dark Rural Horror

Use:
- farms;
- mud;
- rain;
- rotting wood;
- rusted metal;
- old rural infrastructure.

Avoid:
- clean sci-fi;
- generic cyberpunk;
- bright fantasy;
- polished futuristic technology.

---

## 2. Biopunk Decay

Everything should suggest fusion between:
- flesh;
- roots;
- metal;
- machines;
- fungi;
- filters;
- agriculture.

---

## 3. Low-Detail Pixel Art

Prioritize:
- readability;
- strong silhouettes;
- limited colors;
- few frames;
- clean movement.

Avoid:
- overdetailing;
- noisy textures;
- cluttered backgrounds;
- excessive particles.

---

# Palette Rules

Main world colors:
- mud brown;
- rust red;
- dark forest green;
- wet black;
- rotten yellow;
- deep purple;
- toxic green;
- fluorescent cyan.

Contrast rule:

> 90% dark, dirty, muted colors.  
> 10% toxic glow.

Toxic glow must be sparse and meaningful.

---

# Saimon Visual Rules

Saimon must stand out from NPCs without looking heroic.

Required identity:
- purple shirt;
- yellowed cloak;
- beak mask;
- dark pants;
- simple silhouette;
- minimal green filter glow.

Saimon should feel:
- ordinary;
- tired;
- human;
- persistent.

Never make Saimon look like:
- a superhero;
- a cyberpunk assassin;
- a knight;
- a chosen warrior;
- a heavily armored soldier.

---

# NPC Visual Rules

NPCs should:
- wear masks;
- use muted colors;
- look practical;
- look exhausted;
- vary in clothing and silhouette;
- remain less visually iconic than Saimon.

Avoid making all NPCs identical.

---

# Environment Rules

Every environment should communicate:
- moisture;
- contamination;
- decay;
- biological takeover.

Use:
- dark soil;
- toxic puddles;
- organic growths;
- rust;
- wet wood;
- roots;
- fog;
- rain.

Preserve gameplay readability.

---

# Flora Rules

Mutant flora should look:
- alive;
- invasive;
- territorial;
- slightly intelligent;
- wet;
- dangerous.

Avoid generic fantasy plants.

---

# Machine Rules

Machines should look:
- rusted;
- organic;
- painful;
- functional but decayed;
- half-industrial, half-living.

Avoid clean robots.

---

# UI Visual Rules

UI should be:
- minimal;
- readable;
- integrated with survival tone;
- not too decorative.

Use UI sparingly.

---

# Validation Checklist

Before approving visual changes, check:

- Does it look like ToxicLands?
- Is it readable in motion?
- Is it low-detail enough?
- Does Saimon stand out?
- Is toxic glow controlled?
- Does it avoid generic cyberpunk?
- Does it preserve atmosphere?

---

# Response Format After Work

When finished, summarize:

1. visual files changed;
2. palette decisions;
3. consistency with Art Bible;
4. readability concerns;
5. what was intentionally avoided.
