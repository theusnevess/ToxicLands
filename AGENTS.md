# ToxicLands — AGENTS.md

## Project Identity

ToxicLands is a 16-bit dark rural biopunk horror game developed in GameMaker using GML.

Core theme:

> “The world did not die. It adapted.”

The game focuses on:
- atmosphere;
- ecological horror;
- survival;
- toxic environments;
- biomechanical life;
- environmental storytelling.

---

# Engine

- GameMaker
- GML

Never replace the engine.

---

# Protagonist

Saimon.

He is:
- an ordinary man;
- a filter scavenger;
- a traveler;
- not chosen;
- not heroic.

Never transform Saimon into a “chosen one”.

# Development Philosophy

- MVP first
- vertical slices
- one system at a time
- small tasks
- readability first
- atmosphere first
- performance first
- avoid overengineering

---

# Visual Philosophy

- low-detail pixel art
- strong silhouettes
- wet surfaces
- dark palette
- toxic glow used sparingly
- simple readable animations

---

# Workflow

1. Read official docs before implementation.
2. Break work into small tasks.
3. Implement minimally.
4. Validate.
5. Integrate carefully.

---

# Forbidden Behaviors

Never:
- change engine;
- create huge systems without approval;
- contradict lore;
- add multiplayer;
- add procedural generation;
- redesign project structure unnecessarily;
- create generic cyberpunk aesthetics;
- break MVP scope.
