# ToxicLands - Backlog

## Filosofia

O backlog nao e uma lista infinita de ideias.

O backlog contem apenas tarefas com chance real de implementacao e relacao direta com o roadmap.

Toda entrada deve responder:

- Isso melhora ToxicLands?
- Isso aproxima o MVP?
- Isso preserva atmosfera?
- Isso evita complexidade desnecessaria?

---

# Regras De Entrada

Uma tarefa so entra no backlog se tiver:

- objetivo claro;
- fase ou milestone associada;
- escopo pequeno;
- criterio de validacao;
- nenhum conflito com AGENTS.md;
- nenhum conflito com MVP Scope.
